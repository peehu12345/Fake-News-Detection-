# 📰 Fake News Detection using Machine Learning

This project focuses on detecting fake news articles using Natural Language Processing (NLP) and Machine Learning techniques. The model is trained to classify news as **Fake** or **Real** based on textual content.

---


## 📌 Project Overview

Fake news has become a major problem in the digital era. This project uses **TF-IDF Vectorization** and **Logistic Regression** to build an efficient fake news detection system.

The dataset consists of labeled news articles, and the model predicts whether a given news article is fake or real.

---

## 🛠️ Technologies Used

- Python  
- Pandas  
- Scikit-learn  
- TF-IDF Vectorizer  
- Logistic Regression  
- Jupyter Notebook  

---

## 📂 Dataset

The project uses two datasets:
- `Fake.csv` → Contains fake news articles  
- `True.csv` → Contains real news articles  

Each dataset includes text-based news data used for training and testing the model.

---


## ⚙️ Project Workflow

1. Load and merge datasets (`Fake.csv` & `True.csv`)
2. Data cleaning and preprocessing
3. Text vectorization using TF-IDF
4. Splitting data into training and testing sets
5. Model training using Logistic Regression
6. Model evaluation using classification report
